## 给 AI 管家配模型

1. 打开“应用”页。
2. 在应用网格里点“AI 管家（Hermes）”。
3. 在详情页点“打开”。
4. 在 Hermes 的网页里找到模型设置，填上模型服务商和 API 密钥，选一个模型。

模型由 AI 管家自己保管和使用。别的 Agent 和应用各有自己的模型设置，在它们自己的网页或详情页里配。

## 打不开网页

- 如果网页打不开，先打开“应用” → “连接”，查看“状态”。状态是“连接中”时等待连接；显示断开原因时按“连接”页的下一步处理。
- 如果弹窗显示“打不开”以及“还没有连上家里的服务器：…”：先恢复连接，再回到 AI 管家点“打开”。

Wonton App 只负责打开网页，网页里的控件和提示由 Hermes 提供；不要把 API 密钥粘贴到聊天或其他应用中。
