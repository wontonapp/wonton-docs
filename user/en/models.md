## Set up the All-Purpose Bot's model

1. Open the “应用” (Apps) page.
2. Tap “All-Purpose Bot (Hermes)” in the app grid.
3. Tap “打开” (Open) on its detail page.
4. In Hermes's web page, find its model settings, enter your model provider and API key, and pick a model.

The All-Purpose Bot keeps and uses the model itself. Other agents and apps have their own model settings on their own pages or detail pages.

## If the page does not open

- Open “应用” → “连接” (Connection) and check “状态” (Status). Wait if it says “连接中” (Connecting); if it shows a disconnection reason, follow the next step on the Connection page.
- If the dialog says “打不开” (Cannot open) and “还没有连上家里的服务器：…” (Not connected to the home server: …), restore the connection, then tap “打开” again.

Wonton only opens the page; its controls and messages come from Hermes. Do not paste an API key into chat or another app.
